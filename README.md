### What I Build

I wrote 190,000+ lines of Rust to solve one problem: **making AI inference provably correct.**

**[ARC Chain](https://github.com/FerrumVir/arc-chain)** is a Layer 1 blockchain built from scratch for AI agent coordination:

- **7B LLM inference on-chain** — 700x beyond any competitor
- **Bitwise deterministic** across every chip, every architecture
- **33K TPS measured** on real multi-node network
- **STARK proofs** of neural network computation
- **Post-quantum cryptography** (Falcon-512, ML-DSA)
- **GPU verification** — Metal, WGSL, CUDA, AVX-512, NEON

I also build the inference engine (65K LOC), a reasoning model (24K LOC), and enterprise AI governance tools.
